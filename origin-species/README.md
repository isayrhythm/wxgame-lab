# 物种起源

一款适合手机端的开放世界谱系进化小游戏。

## 玩法

- 从核苷酸与短肽体系开始，在无限微环境中收集当前谱系能够利用的资源。
- 绿色目标适合当前代谢方式，灰色目标收益很低或不能利用，黄色与红色生物可能造成伤害。
- 进化能量满后，只能从当前谱系的直接后代中选择下一步。
- 光合、植物和化能自养路线会持续从环境获得能量，不需要捕食也能进化；光照或化学环境会影响速率。
- 不同谱系拥有不同食物偏好：病毒依赖宿主细胞，异养单细胞偏好细菌，动物偏好猎物，真菌偏好有机碎屑，植物偏好光和矿质。

## 谱系树

完整树状图从前生命化学开始，主线经过自复制体系、原始细胞、原核细胞、真核单细胞和多细胞化，并继续展开动物、植物与真菌的代表性门、纲、目、科、属、种路线。病毒样复制体作为依赖宿主的旁支，不作为细胞生命的必经祖先。

## 操作

- 手机：按住屏幕并向任意方向拖动。
- 电脑：拖动鼠标，或使用方向键 / WASD。
- 右下角可随时打开谱系树，横向浏览全部分支。
