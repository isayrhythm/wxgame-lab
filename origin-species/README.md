# 物种起源

一款适合手机端的开放世界吞噬进化小游戏。

## 玩法

- 在地图任意位置按住并拖动，控制变形虫移动。
- 绿色生物比当前角色弱，可以直接接触吞噬。
- 黄色生物与当前角色接近，需要谨慎接触。
- 红色生物更强，接触后会损失生命，并会主动追击玩家。
- 吞噬会增加生物量与变异进度；变异进度满后，从三个分支中选择一个固定下来。
- 世界按区块持续生成，没有可见边界；不同区域拥有不同的生物组成。

## 进化系统

进化树包含吞噬、运动、防御、增殖、感知和共生六类路线，共六轮主要分化。每项进化都有收益和代价，选择会影响后续候选分支。完成主要分化后仍可继续进行性状精炼。

## 操作

- 手机：按住屏幕并向任意方向拖动。
- 电脑：拖动鼠标，或使用方向键 / WASD。
- 右下角可随时查看完整进化树。
